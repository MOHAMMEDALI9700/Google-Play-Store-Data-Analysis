# Google Play Store Data Analysis Using Python

## Project Overview
This project analyzes Google Play Store application data using Python to understand app popularity, user engagement, ratings, pricing, installations, reviews, and app size.

## Objective
To analyze Google Play Store data and identify useful patterns and insights related to app performance and user engagement.

## Dataset
The dataset contains information about Google Play Store applications, including:
- App name
- Category
- Rating
- Reviews
- Size
- Installs
- Type
- Price
- Content Rating
- Genres
- Last Updated
- Current Version
- Android Version

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Top 10 largest applications
- Top installed applications
- Top reviewed applications
- App rating analysis
- Free vs paid applications
- Data cleaning and exploratory data analysis
- Data visualization

## Key Insights
- Free apps generally have higher user adoption.
- Popular apps have very high installation numbers.
- Social and communication apps receive many user reviews.
- Some applications have very large file sizes.
- Highly rated apps indicate positive user feedback.
- Installs and reviews provide useful information about user engagement.

## Conclusion
This project demonstrates how Python can be used to clean, analyze, visualize, and generate insights from real-world Google Play Store data.
